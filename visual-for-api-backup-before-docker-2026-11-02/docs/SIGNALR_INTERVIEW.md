# SignalR в новой версии

Актуальный контракт перенесён в [API_AND_DATABASE.md](API_AND_DATABASE.md),
раздел «SignalR и сохранение в БД».

Задачи сохраняются и читаются через HTTP API и базу данных.
SignalR сообщает `RoomChanged`, после чего React перечитывает комнату из API.
Добавления задач через старый метод Hub `AddTask` больше нет.
Общий код передаётся методом UpdateCode с контролем версии и сохраняется сервером.
